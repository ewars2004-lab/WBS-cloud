# MD期日 — BSOMDスケジュール（カレンダー塗り参照）

MD系WBS行の **期日・工程の正本** は Slack ではなく、調達カレンダーの **塗りつぶされたセル**。

- シート名: `BSOMDスケジュール`
- gid: `394259552`

## シート構造（左側）

| 列 | 内容 | 例 |
|---|---|---|
| A | 年 | 2027 |
| B | シーズン | WI, ES, LA, EA |
| C | ブランド | NOLLEY'S, UNFILO/anysis |
| D | 担当 | namy, sima, Baker |
| E | 作成段階 | 未着手, 転記済み, 完了 |

## カレンダー（F列以降）

- 2行目: 月ヘッダ（2025年5月, 2025年6月, …）
- 3行目: 日（1, 2, 3, …）
- 4行目: 曜日（木, 金, …）
- 各ブランド行: セルに `MD` / `レビュー完了` / `提案リスト` / `FIX` 等のラベル
- **塗りつぶし（背景色）のセル** = その工程の期日・実施タイミングの目安

塗りの意味（運用メモ）:

- **ピンク塗り `rgb(0.957, 0.8, 0.8)` + セル内 `namy`** = 担当MDの期日（1ブランド行につき1セル）。WBSのF列・J列（When）の正本
- **グレー `rgb(0.4, 0.4, 0.4)` / `rgb(0.718, 0.718, 0.718)`** = 週末・祝日の表スタイル。**期日として読まない**
- 調達チームが **緑などで塗ったセル** = 計画値入力などが必要な期日（[MD期限聴取シート](https://docs.google.com/spreadsheets/d/1fO5k91ftfezZol9BvNJWpmC_79O4Yj6H29Py7W5XgAg) 参照）
- ラベル文字（`MD` 等）だけでなく **色付きセル** を優先して読む

カレンダーは **F列（2025年5月）から横に伸びる**。2026年6月はおおよそ **列PN（430）付近**。

## WBS行との対応

WBSの I列メモ / K列Where にある参照文字列で行を特定する。

```
参照元: BSOMDスケジュール 2027 WI NOLLEY'S / namy
```

→ BSOMDスケジュールで `A=2027, B=WI, C=NOLLEY'S, D=namy` の行を探す。

案件名パターン例:

| WBS A列 | カレンダー行 |
|---|---|
| NOLLEYS：WI | 2027 / WI / NOLLEY'S |
| UNFILO/anysis：LA | 2026 / LA / UNFILO/anysis |
| MD / MD関連（NOLLEYS） | メタ行。`MDを期日入れる` 工程が先 |

## MD工程（WBS B列）

標準フロー:

```
MDを期日入れる → 計画作成 → FB → 修正 → 修正FB → 転記
```

- `MDを期日入れる`: カレンダー塗りを見て WBS の F列・When に期日を反映するメタ工程
- 以降の工程: カレンダー上の該当ラベル・塗りと WBS 状態を突き合わせる

## WBS更新チームでの読み方

1. 対象行が **MD系** か判定（下記）
2. I列 / K列 から `年・シーズン・ブランド・担当` を抽出
3. BSOMDスケジュールの該当行を開く
4. **塗りセル** とラベル（MD, レビュー完了 等）から、今どの工程か・次の期日はいつかを推察
5. Slack は補助（FB連絡・報告）のみ。**期日の根拠はカレンダー**

### MD系の判定

次のいずれか:

- A列に `MD` / `NOLLEYS：` / `UNFILO` 等
- B列が `計画作成` / `FB` / `修正` / `修正FB` / `転記` / `MDを期日入れる`
- I列に `BSOMDスケジュール` または K列に調達カレンダーURL

## F列（完了期限）の扱い

| 行種別 | F列 |
|---|---|
| air-closet 案件（AIRCLOSET-*） | **エージェントは編集しない** |
| MD系 | **カレンダー塗りから導出した期日** を F列に反映してよい（`MDを期日入れる` 工程または期日ずれがあるとき） |

カレンダーと WBS の F列 / J列（When）がずれていたら、**カレンダー塗りを正** として F・J・D・I を更新案に含める。

## セル色の取得

`sheets_values_get` では色は取れない。次のいずれか:

- `sheets_get` + `includeGridData: true` を **該当行のみ狭い範囲** で取得（例: `BSOMDスケジュール!A107:BK107`）
- 塗りが取れない場合は Nagi DM に「カレンダー塗りが読めませんでした」と報告し、F列は触らない
